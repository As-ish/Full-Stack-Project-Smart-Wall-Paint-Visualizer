Product requirements, in short

What this demo covers

This build implements the Phase 1 scope from the Smart Wall Paint Visualizer PRD, running entirely client-side so it can be tried without any backend deployed.

Implemented here

  • Room image upload (JPG/PNG)
  • Manual wall selection — magic-wand click and freehand lasso
  • Realistic recolouring that preserves shading and texture
  • Adjustable intensity, multiple walls per photo, undo
  • Before/after comparison
  • Save and download finished designs
  • Admin colour-library management and session KPIs

Backend (separate download)

  • Node.js + Express REST API
  • MongoDB collections for Users, Projects, Colors, Patterns
  • JWT authentication middleware
  • Routes for auth, projects and colour-library CRUD
  • Matches the schema in the PRD's Data Requirements section
  • Ready to run locally or deploy to your own MongoDB + Node host
